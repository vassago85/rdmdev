# Hero background image

Drop a high-quality wide photo here as:

- `hero-home.jpg` (preferred), or
- `hero-home.webp`, or
- `hero-home.png`

Recommended: landscape construction / renovation photo, at least **1920×1080**, compressed for web (~200–400 KB).

The home hero will pick it up automatically. Until then it uses a branded dark gradient fallback.
